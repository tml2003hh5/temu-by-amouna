# Temu by Amouna

موقع وسيط لطلبات منتجات متجر TEMU.
يوفر نموذجًا بسيطًا وأنيقًا حيث يمكن للعميل إدخال بياناته الشخصية 
(الاسم، الهاتف، العنوان) وإرفاق صور المنتجات المراد شراؤها.
يتم إرسال الطلبات مباشرة إلى البريد الإلكتروني مع رسالة تأكيد تلقائية للعميل.

## 🚀 كيفية الاستخدام
1. افتح الموقع عبر GitHub Pages.
2. املأ النموذج بالبيانات المطلوبة.
3. أرسل الطلب وانتظر رسالة التأكيد.
